## 层次职责

| 层 | 代码路径 | 职责 | 禁止 |
|----|---------|------|------|
| 入口 | `src/application/` | 启动、路由 | 不含业务逻辑 |
| 业务 | `src/business/<模块>/` | 核心逻辑 | 不感知 UI |
| 视图 | `src/view/<模块>/` | 页面渲染 | 不直接写数据库 |
